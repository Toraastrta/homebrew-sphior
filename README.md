# Homebrew tap for SPHIOR CODE

```bash
brew install toraastrta/sphior/sphior-scan
sphior-scan run ./src
```

`sphior-scan` is the [SPHIOR CODE](https://github.com/Toraastrta/sphior-code) command line: deterministic
security scanning for hard-coded secrets, insecure patterns mapped to CWE and taint flows. It runs
locally with no account. See the [documentation](https://github.com/Toraastrta/sphior-code#command-line)
for options, CI and SARIF output.
